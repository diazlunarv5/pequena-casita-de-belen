LA PEQUEÑA CASITA DE BELÉN — RECREACIÓN BASADA EN LAS CAPTURAS DE B12

Archivos principales:
- index.html: contenido de la página.
- styles.css: colores, tipografía, espacios y diseño adaptable.
- script.js: menú móvil, año y formulario que prepara un mensaje de WhatsApp.
- assets/referencia-1.jpg a referencia-9.jpg: capturas originales proporcionadas, incluidas como referencia.

IMPORTANTE SOBRE LAS FOTOGRAFÍAS:
Para mostrar las fotos originales como en B12, coloca tus fotografías originales en la carpeta assets y llámalas:
- actividad-infantil.jpg
- juego-aire-libre.jpg
- arte-exploracion.jpg
Las capturas de pantalla están guardadas solo como referencia; no se usan como fotos de la galería. No se incluyen aquí las fotografías individuales originales extraídas de la página.

CÓMO PROBAR:
1. Extrae el ZIP.
2. Abre index.html con Chrome, Edge o Firefox.
3. Necesitarás internet para fuentes web, WhatsApp y Google Maps.

CÓMO MODIFICAR:
- Texto: index.html.
- Estilo y diseño: styles.css.
- Comportamiento del menú/formulario: script.js.

FIDELIDAD:
Esta versión recrea el diseño a partir de capturas, no del código fuente original de B12; por ello no puede garantizarse una copia idéntica píxel por píxel. El logotipo y el mapa son recreaciones provisionales. Para mayor fidelidad, reemplaza el logotipo por el archivo original y usa las tres fotos originales.
El formulario no guarda datos: abre WhatsApp con el mensaje preparado para que la persona lo revise y envíe. El apoyo de Yo Jalisco se describe como sujeto a requisitos, vigencia y disponibilidad.
